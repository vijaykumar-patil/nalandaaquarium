# Tech Stack

## Frontend
- **HTML5:** Semantic markup for structured content.
- **CSS3:** Custom styling for a responsive, modern layout.
- **JavaScript (Vanilla ES6+):** For gallery logic (lightbox), visit counter fetching, and dynamic year updates.

## Media & Assets
- **Video:** MP4 format, hosted locally with `poster` images for optimization.
- **Images:** JPEG, PNG, and SVG for high-quality visuals and icons.
- **Favicon:** Standard icon set for branding and browser support.

## Integrations
- **CounterAPI:** Used for tracking and displaying site visits.
- **WhatsApp API:** `wa.me` integration for direct customer inquiries.
- **YouTube:** Embedding external video content.

## Infrastructure & SEO
- **Static Hosting:** Inferred usage of GitHub Pages or similar static hosting.
- **SEO & Social Meta Tags:** Comprehensive Open Graph (OG) and Twitter card metadata.
- **Structured Data:** JSON-LD for LocalBusiness schema to improve search visibility.
- **CNAME:** Custom domain configuration (`nalandaaquarium.com`).
